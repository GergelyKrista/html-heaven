01 / why this exists

You already
ship reliable /APIs.
Now make people want them.

A game promo page has one job: convince a human with three other tabs open to pre-order, wishlist, or remember your name. It's not a CRUD form. It's a trailer in HTML. Every pixel is performing.

// backend-brain defaults

  • Bootstrap, Tailwind defaults, untouched
  • Roboto / Arial everywhere
  • Centered hero with stock space photo
  • "Learn more" gray button
  • Evenly-gray palette, zero hierarchy
  • Static. No motion. No atmosphere.

// AAA promo defaults

  • Custom display type paired with mono
  • Dominant ink + 1 signature accent
  • Oversized type, grid-breaking layout
  • A CTA that looks like a threat
  • Film-grade depth: grain, scan, vignette
  • Choreographed load, ambient idle motion

The three laws

Internalize these before you touch a single <div>. They override every framework, every template, every "best practice" blog post published after 2019.

01
Tone > taste
Pick one extreme aesthetic. Execute it without compromise. A "balanced" game site has no audience.
02
Hierarchy kills
One thing is 10× bigger than the next. A trailer frame. A gigantic title. A single button. The eye needs a destination.
03
Motion = alive
Even when the user doesn't move, something on the page must. Scan lines. Grain. Drift. Absence of motion reads as "broken".
04
Ship < 100kb
Gamers have spotty connections and are allergic to loading screens outside the game. Cloudflare Pages makes this trivial.
02 / stack.config

The Cloudflare
edge rig.

You are not spinning up a k8s cluster. You are shipping static HTML with three worker functions and calling it a day. Here is the entire stack, mapped to your server-brain.

framework

Astro 4.x

Ships zero JS by default. Islands only where needed. MDX for the story page. Feels like SSR Rails, renders like static HTML.
hosting

Cloudflare Pages

git push → live in 40s. Free plan covers your launch day. Automatic branch previews for the art director to reject.
edge logic

Workers

Newsletter signup, keycode redemption, press-kit gating. Deno-ish runtime, milliseconds cold. Your old job, but smaller.
storage

R2 + KV

R2 for trailers, screenshots, press kits (S3-compatible, no egress fees). KV for signup lists, feature flags, localized strings.
media

Cloudflare Stream

Auto-encode your 4K trailer once, adaptive-bitrate delivery everywhere. Works on a potato phone in rural Patagonia.
images

Images / Polish

Variants on the fly. WebP + AVIF without you lifting a finger. Your key art weighs 380kb instead of 4mb.
data

D1 (SQLite)

Only if you need a leaderboard, wishlist counter, or a lore-wiki search. Otherwise skip it — you do not need a DB for a landing page.
observability

Web Analytics

Privacy-friendly. No cookie banner. Shows you which trailer people actually watched vs. closed at :06.

// type doctrine

  1. Ship two fonts. Three max. A display for shouting, a body for everything else, optional serif for counterpoint. Every extra font is a tax.
  2. Scale is emotion. Your hero title should be at least 12vw. A "big" heading at 32px is not a heading, it's a paragraph that's having a bad day.
  3. Tighten the tracking on large type. letter-spacing: -0.02em on anything above 60px. Always.
  4. Mono for meta. Timestamps, stats, counters, labels. Mono signals "this is information, not marketing copy."
  5. Italic serif is a spice. One pullquote. One tagline. Overuse and it reads like a wedding invitation, not a game.
  6. Load with <link rel="preconnect">. Swap strategy: font-display: swap. Invisible text is a worse crime than a font flash.
03 / visual.grammar ~ color

Pick a genre.
Steal the palette.

Game promo palettes are not neutral. They telegraph genre in 2 seconds. Chrome-and-blood reads as cyberpunk. Moss-and-gold reads as fantasy. Don't invent from scratch — borrow the rules your genre already trained players to expect, then push the accent one shade further than feels safe.

60 / 30 / 10
60% void / base, 30% ink / mid, 10% your one signature accent. Never split your 10 across three accents — a palette with three shouts has no shouts.
earn your neon
Neon is a reward, not a background. Reserve it for the CTA, the key stat, the one word that matters. A site that glows everywhere glows nowhere.
check contrast
Body text needs 4.5:1 against its background. Neon yellow on white is a hate crime against your players. Test in the actual dark-room / sunlit-phone conditions.

05 / motion.core

Motion is the
difference between
dead and divine.

Every page should breathe. Three kinds of motion earn their keep: load choreography (staggered reveal on first paint), ambient idle (the page feels alive even when nothing happens), and hover response (instant feedback that respects the user's input).

load choreography

Stagger reveal on first paint. 80ms between children. Elements translateY(24px) + blur → rest. The eye follows the sequence and reads in intended order.

VEIN·2026

ambient idle

A scan line drifts. A glyph flickers. Grain jitters. Motion that requires nothing from the user but signals the page is a live broadcast, not a printed poster.

hover response

Movement starts in <100ms of the mouse entering. Slow responses feel broken. Use transform + filter, never top/left. GPU wins the race.

scroll parallax

Background layers travel slower than foreground. Creates cinematic depth. Use transform: translate3d(0, calc(var(--scroll)*-0.3px), 0) and a rAF-throttled scroll handler.

VEIN
RUNNER

marquee ritual

One horizontal band, one direction, slow crawl. Read as news ticker or secret broadcast. Pause on hover if it carries actual content.

PRE-ORDER LIVE·PS5 / XSX / PC·2026.11.13·PRE-ORDER LIVE·PS5 / XSX / PC·2026.11.13·

honor prefers-reduced-motion

Some players get nauseous. Some just hate it. Wrap every keyframe rule in @media (prefers-reduced-motion: no-preference). Ship a calm version by default; turn the machine on only when it's welcome.

07 / deploy.protocol

Ship it to
the edge.

Eight steps from empty directory to a promo site live on 300 Cloudflare data centers. Assumes you have a Cloudflare account and a git repo. Total time: about 18 minutes, most of which is waiting for npm install.

01

Scaffold Astro

npm create astro@latest veinrunner-promo — choose "Empty", TypeScript strict, skip sample. Astro because it ships zero JS by default, and you will like that.

02

Install the edge toolchain

npm i -D wrangler @astrojs/cloudflare, then add the adapter to astro.config.mjs. This is what lets you call Workers bindings from Astro pages.

03

Wire assets to R2

Upload your trailer, screenshots, and press kit: npx wrangler r2 object put veinrunner-media/trailer.mp4 --file ./trailer.mp4. Public-read via a Worker route or a custom domain.

04

Newsletter signup = one Worker

POST /api/signup → writes email to KV. 22 lines of code. No "service". No queue. See snippet on the right.

05

Connect repo to Pages

Cloudflare dashboard → Pages → "Connect to Git" → pick your repo. Build command npm run build, output ./dist. Every push is a preview URL.

06

Custom domain + redirects

Add veinrunner.game in Pages → Custom domains. Cloudflare handles DNS, SSL, and HTTP/3. Add a _redirects file for legacy URLs: /press/* https://press.veinrunner.game/:splat 301

07

Turn on Polish + Stream

Polish auto-converts images to WebP/AVIF. Stream encodes your trailer once and serves adaptive bitrate. Together they cut your payload by 60–80%.

08

Prewarm and pray

npx wrangler pages deploy on launch morning. Watch Web Analytics. Drink coffee. If it falls over, it's not the edge — it's whatever you put behind the edge.

export async function onRequestPost(ctx) {
  const { email } = await ctx.request.json();
  if (!/^[^@\s]+@[^@\s]+$/.test(email))
    return new Response("bad email", { status: 400 });

  await ctx.env.SIGNUPS.put(
    `e:${email}`,
    Date.now().toString(),
    { metadata: { ua: ctx.request.headers.get("user-agent") }}
  );

  return Response.json({ ok: true });
}
